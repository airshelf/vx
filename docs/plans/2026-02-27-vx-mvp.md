# vx — Fast Vercel CLI Replacement (MVP)

**Date:** 2026-02-27
**Status:** COMPLETE

## Summary

Build `vx`, a thin Bun-based CLI that wraps Vercel's REST API directly. Fixes the pain points we hit daily: hanging logs, silent project mislinks, noisy output, no JSON mode. MVP ships 4 commands: `ls`, `logs`, `env`, `domains`. Every command supports `--json` for piping. Auth reads existing Vercel CLI tokens — zero config for existing users.

## Architecture

```
src/
  cli.ts            # Entry point, commander setup
  config.ts         # Auth token + team + project resolution
  api.ts            # Vercel REST API client (fetch-based)
  format.ts         # Table/color output helpers
  commands/
    ls.ts           # List deployments
    logs.ts         # Stream deployment logs
    env.ts          # List/manage env vars
    domains.ts      # List domains
```

Dependencies: `commander` (subcommands), `picocolors` (colors). That's it.

### Task 2: API client + format helpers
**Files:** `src/api.ts`, `src/format.ts`
**Steps:**
1. Create `src/api.ts` exporting `vercel(path: string, opts?: { method?: string, body?: unknown }): Promise<any>`:
   - Calls `getConfig()` from `./config.ts`
   - Builds URL: `https://api.vercel.com${path}`, appends `?teamId=X` or `&teamId=X` if config.teamId exists
   - Sets headers: `Authorization: Bearer ${config.token}`, `Content-Type: application/json`
   - On non-2xx: throw `Error(\`Vercel API ${res.status}: ${await res.text()}\`)`
   - On `X-RateLimit-Remaining` header < 10: `console.error` warning to stderr
   - Also export `vercelStream(path): Promise<Response>` for streaming endpoints (logs) — same auth, returns raw Response
2. Create `src/format.ts` exporting:
   - `table(headers: string[], rows: string[][])`: pad each column to max width + 2, print header row, separator line of dashes, then data rows. Use `process.stdout.write` for no trailing newline issues
   - `relativeTime(ts: number): string`: `Date.now() - ts` → "just now" (<60s), "Nm ago" (<60m), "Nh ago" (<24h), "Nd ago"
   - `stateColor(state: string): string`: import `pc` from picocolors, READY/READY→green, ERROR/CANCELED→red, BUILDING/INITIALIZING→yellow, QUEUED→dim, default→white
   - `outputJson(data: unknown)`: `process.stdout.write(JSON.stringify(data, null, 2) + "\n")`

**Verify:**
```bash
bun -e "import { vercel } from './src/api.ts'; import { table, relativeTime } from './src/format.ts'; console.log(typeof vercel, relativeTime(Date.now() - 60000))"
```
**Done when:** import check prints `function 1m ago`
- [x] Task 2 complete

### Task 4: `vx logs` — stream deployment logs
**Files:** `src/commands/logs.ts`, `src/cli.ts` (register command)
**Steps:**
1. Create `src/commands/logs.ts` that:
   - Takes deployment URL or ID as required positional arg (strip `https://` prefix if present)
   - Uses `vercelStream()` from api.ts to call `GET /v3/deployments/{idOrUrl}/events?follow=1&builds=1&direction=forward`
   - Reads response body as stream: `for await (const chunk of response.body)`, parse newline-delimited JSON
   - Each event: print `[timestamp] [level] message` with color (info=dim, warning=yellow, error=red)
   - Options: `--follow` / `-f` (default true — set `follow=1`), `--no-follow` (set `follow=0`, fetch and exit), `--json` (print raw event JSON per line)
   - AbortController with `--timeout N` ms (default 30000): on timeout, print `stderr: "Timed out after Ns (use --timeout to extend)"` and `process.exit(0)`
   - On fetch error or empty response: print clear message to stderr, exit 1
2. Register `logs <url>` command in `src/cli.ts` via `program.command("logs <url>")`

**Verify:**
```bash
bun run src/cli.ts logs --help
```
**Done when:** `vx logs --help` shows url arg and options; with valid token, `vx logs <url>` streams colored log lines
- [x] Task 4 complete
